# 👁️ Olho Amigo

Detector de objetos com áudio para acessibilidade de pessoas com deficiência visual.

**TCC Técnico em Informática - IFPB (2024)**

## 📋 Tecnologias

- **YOLO v8** - Detecção de objetos
- **OpenCV** - Processamento de imagens
- **gTTS** - Síntese de voz em português
- **Python** - Linguagem principal

## 🚀 Como Usar

### 1. Instale dependências

```bash
pip install -r requirements.txt
```

### 2. Execute

```bash
python main.py
```

### 3. Use a câmera

- Aponte para objetos
- Sistema detecta e fala em português
- Pressione Q para sair

## 📁 Estrutura

```
OlhoAmigo/
├── main.py           # Código principal
├── requirements.txt  # Dependências
└── README.md        # Este arquivo
```

## ⚙️ Requisitos

- Python 3.8+
- Câmera (webcam)
- Alto-falante
- Conexão com internet (para gTTS)
